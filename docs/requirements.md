# 需求分析与功能清单

> 最后更新: 2026-06-29

## 问题定义

空管日常不缺确定性的前置信息——计划时刻表提前一周可知、气象预报由气象局提供、军航通告有前置渠道。规则引擎利用这些信息，能把基础流量预估做到八九成准。

**本系统的核心价值不在于替代规则引擎，而在于捕捉确定性信息覆盖不了的"剩余不确定性"**：

1. 用自然语言快速查询航班、法规、流量，替代在多系统之间人工切换
2. 用 Autoencoder 检测实际流量与正常模式的偏差——不管前置信息是什么，最终结果会体现为流量数据走样，这是规则引擎和人工都难以实时捕捉的

## JD 对照

### 职位要求第4条：大模型应用

| 子项 | 实现方式 |
|------|---------|
| RAG 检索增强生成 | LangChain + Chroma 向量库 + text2vec-base-chinese 本地 Embedding，构建空管法规知识库问答 |
| Agent 智能体 | LangGraph ReAct Agent，支持航班查询/法规检索/流量查询/LSTM预测/异常检测 5 工具 |
| 向量数据库 | Chroma (轻量级，本地持久化) |
| 文档切片与索引 | RecursiveCharacterTextSplitter，chunk_size=500, overlap=50 |

### 职位要求第5条：传统深度学习

| 子项 | 实现方式 |
|------|---------|
| 深度学习框架 | PyTorch 2.x |
| 时序预测 | LSTM (hidden=64, layers=2)，输入24h历史流量，输出24h预测 |
| 异常检测 | Autoencoder (24→16→8→16→24)，z-score 双向异常判定 |

### 职位要求第1-3条：数据治理

Demo 通过合成数据生成器模拟端到端数据链路：
- 数据采集与清洗：generate_flights / generate_flow_history，缺失值处理、异常值过滤
- 数据标准：统一机场ICAO代码、航班号格式、状态枚举
- CAAC 2024 公报校准：延误率、月度波动、起降分布等真实统计参数
